# Sleeper fixtures

**Synthetic.** Shaped on a Sleeper league captured 2026-10-28 (Sleeper's public
2018 docs example). Every id, username and team name here is invented.
`scoring_captured.json` and the league's `scoring_settings` are that league's 81
scoring settings verbatim -- settings, not personal data -- plus, in
`league.json`, a TE premium and a 100-yard rushing bonus to exercise both mappings.

The plan's acceptance asks for a redacted capture of the owner's real league
too. That waits on the owner's Sleeper username; until then the real-league
gate is **not** passed.
