# League prerequisites S0 — evidence and review

## Changes

PlayerMatcher uses stored provider ID, GSIS, ESPN, normalized name + position,
birth date to resolve ties, name + birth date across positions, then explicit
overrides. Name matching never accepts an ambiguous result. Conflicting stored
IDs are refused. Birth dates from the sources can disagree: a unique name and
position still match, as specified in the plan.

SleeperCrosswalk fetches the full player snapshot once per daily ingest, capped
at 32 MiB, and writes Sleeper/Yahoo IDs transactionally. It preserves unrelated
IDs, refuses conflicting Sleeper replacements and Yahoo IDs owned by other
players, and skips duplicate provider records for one player. Four explicit
GSIS-based nickname exceptions seed the audited override table without replacing
manual entries: Tinsley, Knight, Ogletree and Hibner.

V10 adds the override table and the ESPN expression index on players. Existing
migrations and player_game_stats indexes are unchanged. S1 now uses V11.

ProjectionController sorts by the raw total before paging. JSON keeps rounded
points and omits the internal raw value. Profile ownership remains checked
before scoring.

modifying the source database. Applied the actual crosswalk to a disposable

local mirror (through week 5), not a claim about all current NFL rosters.

  agree, so added an explicit override using GSIS 00-0040879 and Sleeper 13324.

## Remaining work and argument against merging

No league import, ROS evaluator, Trades, ESPN or Yahoo connection is built.
Browser QA is still outstanding. The coverage population is a stale local
mirror; repeat measurement on a refreshed population before claiming broader
coverage. Name and position alone cannot prove identity, so manual audit and
explicit exceptions remain necessary. Overrides intentionally cannot repair
conflicting already-stored IDs automatically.

The PR also carries the previously missing projection backend; that larger
integration warrants review before merge. No production writes or deployment
were performed, and projection generation remains disabled.
