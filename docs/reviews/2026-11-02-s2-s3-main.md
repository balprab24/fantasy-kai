## What I did not fix, and why

- The model's calibration failure is a product hold, not a failing implementation test. No fourth
  attempt, relaxed threshold or Trades UI was introduced.
- Flat projections, reserve-list return dates, nonlinear bonuses evaluated at a mean, one sigma fit
  across rulesets and missing slot-level explanations remain the documented model limitations.
- No fresh real-league import: owner Sleeper identity is still missing. Prior seeded browser QA in
  the S2 review is historical evidence, not a fresh real import. This session's browser was unavailable.
- The local mirror is stale (last pull October 14, complete through week 5); no ingest was needed
  to verify these code changes. Landing captures were deliberately not refreshed.
- Production still runs a pre-leagues image at schema V6. Its deploy is separately prepared and
  awaiting authorization. Frontend PR checks do not deploy this API.

## The argument against this change

This PR combines useful S2 reads with a model whose product gate failed. Merging must not be read
as releasing calibrated trade advice. The needs panel also gives precise-looking differences
without showing their uncertainty. Keep Trades inaccessible and judge the readout on a real league
before claiming that it improves decisions. A real-league mismatch, ownership failure or a new
production endpoint exposing the held model would falsify readiness.
